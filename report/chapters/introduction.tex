Fiorino is an encrypted file manager that 
\href{https://www.youtube.com/watch?v=te7XM8RCfxQ}{won't let you pass unnoticed}.

It comes both as a set of CLI executables and as a C API. The supported platform
is GNU/Linux. The code uses POSIX.1-2008 interfaces, OpenSSL 3.x APIs, and some
BSD/Linux extensions/interfaces.

\paragraph{Relevance to Secure Programming}
It is relevant to the ICS0022 (Secure Programming) materials as it displays a set
of protections against studied CWEs as well as careful error handling.
More on this in the later chapters.

\paragraph{Addressed CWEs}
The abovementioned CWEs that are addressed/prevented include but are not limited to...

\begin{itemize}
    \item \texttt{NULL} pointer dereferencing
    \item buffer overflows
    \item string formatting vulnerabilities
    \item TOCTOU
\end{itemize}
